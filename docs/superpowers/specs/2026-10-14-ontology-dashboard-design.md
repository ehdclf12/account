# 홈 대시보드 — 성운 허브(F) 설계

2026-10-14

## 목표

Budget 기능을 제거한 뒤(커밋 `6ece72e`) 남은 Calendar · Archive · Time을 **한 화면에서
연결된 그래프로** 보는 개인 비서형 홈을 만든다. 현재 홈(버튼 3개 목록)을 대체한다.

- 가운데 **'나 · TODAY' 허브**에서 4개 영역 성단이 사방으로 뻗는다.
- 각 영역에 **지금 중요한 항목이 자동으로** 노드로 뜨고, 실시간으로 갱신된다.
- 노드를 누르면 **그 항목/날짜가 열린 상태로** 해당 화면에 들어간다.
- 앱 전체를 **다크로 고정**한다.

## 범위

이번 단계는 홈 대시보드 + 딥링크 + 다크 고정만 한다. 새 테이블·API는 없다.
알림함·푸시·손동작은 후속 단계다(맨 아래 "후속 단계" 참고).

## 화면 (시안 F · `.superpowers/brainstorm/…/glow-v8.html`)

세로 휴대폰 화면 하나. 배경은 순수 검정에 가까운 짙은 남색 방사 그라디언트.

```
 10.14 TUE · 21:12                ● LIVE  ⏻
      · 세금신고 D+1                 · 병원 10/16
    (Deadline →) ·  ·             · (Calendar →)
         ·   ↖    ·  ·   ·  ·    ↗    ·
           ·  [ ◉ 나 · TODAY ]  ·
         ·   ↙    ·  ·   ·  ·    ↘    ·
    (Archive →)  ·                  · (Time →)
      · 📌 레시피                  · ● 공부 0:42
```

- **상단 바**: 날짜·시각(1분마다 갱신), `● LIVE`, 로그아웃 `⏻`(확인창 후 로그아웃).
- **허브**: 가운데 원 + 사각 프레임(첫 참고 이미지의 중앙부). 라벨 `나 · TODAY`.
- **영역 노드 4개**(고정 위치): Deadline(좌상, 빨강/주황) · Calendar(우상, 초록) ·
  Archive(좌하, 파랑) · Time(우하, 보라). 허브와 화살표 직선으로 잇는다.
  라벨 `Deadline →` 등을 누르면 해당 화면(`/archive`, `/calendar`, `/time`)으로 간다.
  Deadline 영역 노드는 `/calendar`로 간다(기한 보기 화면이 Calendar이므로).
- **항목 노드**: 영역 노드 둘레에 호(arc) 모양으로 놓는다. 점 + 짧은 라벨.
- **먼지 노드**: 허브·영역 주변의 작은 점과 가는 선. **장식이며 누를 수 없다.**
  고정 시드 난수로 만들어 렌더마다 모양이 바뀌지 않는다. 일부가 천천히 깜빡인다.
- **하단 메뉴 없음.** 화면 이동은 영역/항목 노드로만 한다.

### 급한 정도 표현

F는 위치로 순서를 보여주지 않으므로 **크기·밝기·깜빡임**으로 표현한다.

| 상태 | 표현 |
|---|---|
| 기한 지남 / 오늘 | 빨강, 가장 크게, 깜빡임 |
| D-1 ~ D-2 | 영역색, 크게, 밝게 |
| D-3 ~ D-7 | 영역색, 작게, 흐리게 |
| 진행 중인 시간 기록 | 보라, 맥박(크기 변화) |

## 노드 자동 선택 규칙

모두 `src/lib/dashboard.ts`의 순수 함수가 계산한다. 입력: Archive 항목, 시간 세션,
시간 블럭, 목표, 공휴일, 현재 시각. 출력: 영역별 노드 목록.

| 영역 | 대상 | 정렬 | 최대 | 누르면 |
|---|---|---|---|---|
| Deadline | `calendarItems()` 중 카드 완료(`done`)도 `isAllDone()`도 아니고 기한 ≤ 오늘+7(지난 것 포함) | 기한 오름차순 | 5 | `/archive?item=<id>` |
| Calendar | 오늘~+14일 중 공휴일이 있거나 기한 항목이 있는 **날짜** (`10/16 · 2건`, `10/9 한글날`) | 날짜 오름차순 | 3 | `/calendar?date=<YYYY-MM-DD>` |
| Time | ① 진행 중 세션(`ended_at` null) `● 공부 0:42` ② 오늘 누적 상위 블럭 ③ 서브목표가 남은 목표 `독서 60%` | ①→②→③ | 4 | `/time` |
| Archive | `pinned && !archived` 항목 | `updated_at` 내림차순 | 3 | `/archive?item=<id>` |

- 최대 개수까지만 노드로 보이고, 넘친 개수는 그 다음 자리에 `+N` 노드로 표시한다. 누르면 그 영역 화면으로 간다.
- **같은 날 연결**: Deadline 노드 중 기한이 같은 것끼리 보라 점선 + `⚡ 같은 날`.
- 시간 기록은 **본인(`who`) 것만**(기존 훅이 이미 그렇게 조회한다). Archive는 공용이다.
- 데이터는 기존 훅을 그대로 쓴다: `useArchiveItems`, `useTimeSessions`, `useTimeBlocks`,
  `useTimeGoals`, `useHolidays`. 기존 `useRealtime` 구독으로 자동 갱신된다.

## 딥링크

| 주소 | 동작 |
|---|---|
| `/archive?item=<id>` | Archive가 그 항목의 상세 팝업(`detail` 상태, 바둑판 카드 탭과 같은 팝업)을 연 채로 시작 |
| `/calendar?date=<YYYY-MM-DD>` | Calendar가 그 날짜를 `selected`로, 그 달을 `cursor`로 시작 |

- 쿼리 파싱은 `src/lib/deeplink.ts` 순수 함수로 분리한다.
- 데이터 로딩이 끝난 뒤에도 없는 id(삭제됨 등)나 형식이 틀린 날짜는 **무시**하고 기본 화면.
- 팝업/날짜를 연 뒤에는 쿼리를 지운다(`replace`) — 뒤로 가기·새로고침 시 다시 열리지 않게.
- 메뉴에서 평소처럼 들어오면 기존과 동일하다.

## 다크 고정

- `main.tsx`에서 `applyTheme('dark')`로 고정한다.
- `ThemeToggle.tsx` 삭제, `theme.ts`의 `loadTheme`/`saveTheme`와 해당 테스트 삭제.
  `applyTheme`(상태바 색 포함)은 유지한다.
- Calendar·Archive·Time은 기존 `[data-theme='dark']` 토큰을 그대로 쓴다.
  홈 대시보드만 별도 배경(검정 계열)을 쓴다.

## 구현 구조

| 파일 | 역할 |
|---|---|
| `src/lib/dashboard.ts` (신규) | 노드 선택·정렬·최대 개수·급한 정도·같은 날 연결 계산 |
| `src/lib/deeplink.ts` (신규) | `?item=` / `?date=` 파싱·검증 |
| `src/lib/nebula.ts` (신규) | 고정 위치(영역 중심, 항목 호 배치)와 시드 난수 먼지 노드 좌표 |
| `src/components/dashboard/Nebula.tsx` (신규) | SVG 전체 그리기(허브, 영역, 항목, 먼지, 연결선) |
| `src/screens/HomeMenuScreen.tsx` | 버튼 목록 → 상단 바 + `Nebula` |
| `src/screens/ArchiveScreen.tsx`, `CalendarScreen.tsx` | 딥링크 초기 상태 반영(최소 수정) |

- **SVG + CSS 애니메이션만** 사용한다(WebGL·캔버스 라이브러리 없음). 새 의존성 없음.
- `viewBox="0 0 240 420"` 고정, 화면 폭에 맞춰 확대. 누르는 영역은 라벨 둘레에
  투명 사각형을 깔아 **실제 화면 기준 32px 이상**으로 잡는다.
- 진행 중 시간 표시를 위해 홈에서만 60초 간격 시계를 돈다.
- `prefers-reduced-motion: reduce`이면 깜빡임·맥박·먼지 애니메이션을 끈다.

## 예외 상황

- **로딩 중**: 허브·영역 노드·먼지만 먼저 그리고, 항목 노드는 데이터가 오면 나타난다.
- **조회 실패**: 그 영역 노드 아래에 `불러오지 못했어요`를 작게 표시. 다른 영역은 정상.
- **항목이 하나도 없음**: 허브 아래 `오늘은 비어 있어요`를 은은하게 표시.
- **라벨 겹침**: 라벨은 최대 8자로 자르고(`…`), 항목 호의 각도 간격을 개수에 맞춰 벌린다.

## 후속 단계 (이번 범위 아님, 결정 사항 기록)

1. **앱 안 알림함** — 알림 항목 테이블, 생성 로직, 알림함 화면, 홈 상단 `🔔 N` 배지.
   항목: 오늘 마감 · 기한 지남 · 내일 마감 · 오늘 일정 · 공휴일.
   **체크 = "확인했음" 표시만** 한다. 실제 체크리스트 완료는 Archive에서 한다.
2. **푸시 알림** — 하루 1회, 문구 "오늘의 일정을 체크해주세요", 누르면 알림함.
   **발송 시각은 사용자별 설정**(기본 06:00, 10분 단위). Supabase `pg_cron`이 10분마다
   발송 API를 호출하고, 같은 날 중복 발송은 발송 기록으로 막는다(Vercel Hobby 크론은
   하루 1회·±59분이라 쓰지 않는다). 아이폰은 홈 화면에 추가한 PWA에서만 수신(iOS 16.4+).
3. **손동작 인식** — 카메라 기반, 기기 내 처리. 아이폰 실기기 스파이크로 가능성 확인 후 결정.
